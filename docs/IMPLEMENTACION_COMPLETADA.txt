💡 FLUJO DE TRABAJO TÍPICO
═══════════════════════════════════════════════════════════════════════════════

USER STORIES COMPLETADOS:

1. ADMIN CREA USUARIO
   [Panel Admin] → Gestión de Usuarios → Crear Usuario
   ✓ Define nombre, email, contraseña, rol

2. TRABAJADOR INICIA SESIÓN
   [Login] → Ingresa credenciales
   ✓ Accede a su dashboard personalizado

3. TRABAJADOR CREA SESIÓN
   [Dashboard] → Nueva Sesión
   ✓ Sube documentos y comienza procesamiento

4. ADMIN SUPERVISA
   [Panel Admin] → Gestión de Sesiones
   ✓ Ve progreso de todos los trabajadores

5. ADMIN REASIGNA (si necesario)
   [Sesión] → Reasignar
   ✓ Cambia trabajador + registra motivo en auditoría

6. TRABAJADOR FINALIZA
   [Sesión] → Marcar como completada
   ✓ Genera reportes
